# ภาพรวมการ Clean ข้อมูล NDT7 (5 ประเทศ)

สรุปว่าทำอะไรไปแล้วบ้าง ตั้งแต่ข้อมูลดิบจนได้ clean parquet พร้อมทำ EDA
(รายละเอียดคอลัมน์อยู่ใน `README_for_eda.md`, วิธีจัดหมวดแบบเต็มอยู่ใน `paper/methodology_isp_classification.md`)

## 1. ข้อมูลต้นทาง

- **แหล่ง:** M-Lab NDT7 speed test (ดึงจาก BigQuery) ช่วงปี 2023–2025
- **ประเทศ:** เวียดนาม, มาเลเซีย, พม่า, กัมพูชา, ลาว (5 ประเทศ)
- ข้อมูลดิบอยู่ที่ `mlab_results/mlab_<country>/*.parquet`

## 2. ขั้นตอนที่ทำ (pipeline)

```
ข้อมูลดิบ (raw)
   │
   ├─ [1] Clean       ตัดแถวที่เป็นไปไม่ได้ทางกายภาพ
   ├─ [2] Null check  ตรวจค่าว่าง
   ├─ [3] Classify    ตรวจ IP จริงว่าเป็น mobile/broadband/hosting (วิธี SRS — ดูข้อ 4)
   └─ [4] Province    ติดหน่วยพื้นที่ (จังหวัด/รัฐ) ด้วย point-in-polygon
        │
        ▼
   clean parquet  (data/<country>/mlab_<country>_clean.parquet)
```

โน้ตบุ๊กที่ใช้: `notebooks/<country>/mlab_<country>_clean_v2.ipynb`
(สร้างจาก generator เดียวกัน `notebooks/build_clean_nb.py` — ทุกประเทศ logic เหมือนกันเป๊ะ)

## 3. Clean ตัดอะไรทิ้งบ้าง

ตัดแถวที่ค่าเป็นไปไม่ได้ (ไม่ใช่การวัดจริง):
- `mean_throughput_mbps <= 0` (ไม่มีความเร็ว = โหลดไม่สำเร็จ)
- `duration <= 0`
- `min_rtt < 0`
- `loss_rate` นอกช่วง [0, 1]

| ประเทศ | แถวดิบ | หลัง clean | ตัดทิ้ง |
|---|---|---|---|
| เวียดนาม | 24,927,205 | 24,667,548 | 259,657 (1.04%) |
| มาเลเซีย | 6,730,391 | 6,637,691 | 92,700 (1.38%) |
| พม่า | 2,182,872 | 2,115,739 | 67,133 (3.08%) |
| กัมพูชา | 785,395 | 770,501 | 14,894 (1.90%) |
| ลาว | 143,881 | 139,693 | 4,188 (2.91%) |

## 4. จัดหมวดประเภทเน็ต (`category`) — หัวใจของงาน

**ปัญหา:** NDT7 ไม่มี field บอกว่าเป็นเน็ตมือถือหรือเน็ตบ้าน ต้องหาเอง
**วิธีเดิมที่ทิ้งไป:** เดาจากชื่อ ISP → ไม่แม่น (telco รายใหญ่มีทั้งมือถือทั้งบ้านในชื่อเดียว)
**วิธีที่ใช้:** ตรวจ IP จริงผ่าน ip-api.com แบบมีหลักสถิติ:

1. **สุ่มตัวอย่าง (simple random sample)** IP ของแต่ละ ISP ตามสูตร Cochran
   → n = 16,588 ต่อ ISP (99% confidence, ±1%)
   ISP เล็ก (IP ≤ 16,588) → ตรวจครบทุกตัว
2. **ตัดสินต่อ ISP** ด้วย Wilson 99% CI เทียบเกณฑ์ 99%:
   - บริสุทธิ์ทางเดียว >99% → เหมาทั้ง ISP (Mobile หรือ Consumer Broadband)
   - ปนกัน (mixed) → **ตรวจ IP ครบ 100%** แล้วติดป้ายราย IP (per-IP override)
3. **hosting/CDN** แยกออกด้วย flag ของ ip-api + รายชื่อ cloud/CDN (Cloudflare, AWS, Akamai ฯลฯ)

ได้ 3 หมวด: `Mobile` / `Consumer Broadband` / `Hosting/Datacenter`

**ตรวจสอบความถูกต้องแล้ว** (validate กับข้อมูลจริงที่รู้คำตอบทั้ง population):
sample คลาดจากค่าจริงไม่เกิน ±0.7% ทุกกรณี — ยืนยันว่าการสุ่มแม่นจริง

## 5. ติดหน่วยพื้นที่ (`province`)

จับพิกัด (lat/long) เข้ากับขอบเขตการปกครองระดับใหญ่สุด ด้วย point-in-polygon:
- เวียดนาม 63 จังหวัด · กัมพูชา 25 จังหวัด · ลาว 18 แขวง · พม่า 15 รัฐ/ภาค · มาเลเซีย 16 รัฐ
- ขอบเขตจาก **geoBoundaries** (ADM1, Open Database License)
- **ครบ 100% ไม่มี null** ทุกประเทศ

## 6. สถานะ

| ประเทศ | สถานะ |
|---|---|
| เวียดนาม, มาเลเซีย, พม่า, กัมพูชา, ลาว | ✅ **เสร็จ พร้อมทำ EDA** |
| ฟิลิปปินส์ | ⏳ กำลัง fetch ข้อมูลเพิ่ม (ISP ใหญ่ยังตรวจ IP ไม่ครบ) |
| ไทย | มี clean แยกต่างหาก (คนละ pipeline) |
| อินโดนีเซีย | ยังไม่เริ่ม (ข้อมูลใหญ่มาก 372M แถว) |
